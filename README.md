SPS Tic Tac Toe 🧠🎮

A Fusion of Rock-Paper-Scissors and Tic Tac Toe
📌 Overview

SPS Tic Tac Toe blends two classic games—Rock-Paper-Scissors (SPS) and Tic Tac Toe—into one fun and strategic experience. To place your symbol (X or O) on the board, you must first win an SPS round, adding unpredictability and challenge to the traditional Tic Tac Toe gameplay.
🎯 Objective

Win by getting three symbols in a row (horizontally, vertically, or diagonally), but only after winning a Rock-Paper-Scissors match to earn each move.
⚙️ Tech Stack

Built with React.js, using HTML, CSS, and JavaScript.
